# Client Onboarding

## Purpose
Turn a new client conversation into a scoped project with agreed expectations
— before any work starts.

## Process
1. **Intake** — capture: who, the job to be done, current state, constraints
   (budget, dates, access), success definition.
2. **Discovery questions** — the 5-10 questions that expose real requirements
   (what does done look like? what breaks if it's late? who decides?).
3. **Scoping** — deliverables, non-goals, assumptions, dependencies.
4. **Proposal** — offer, timeline, price, terms (see proposals skill).
5. **Kickoff** — project created with requirements recorded; channel(s) created;
   communication rhythm agreed; decision process defined.

## Rules
- Requirements recorded in the project, not just email.
- Say "no" or "out of scope" explicitly — implied scope is how agencies bleed.
- Set the escalation path (who to contact, how, when).
