# Landing Page Design

## Purpose
Build a single-message page that converts: one audience, one offer, one
action — with proof.

## Structure (above the fold is a contract)
1. **Hero** — headline (the outcome, in customer language) + subhead (the
   mechanism) + primary CTA + proof snippet (real number/logos) + no nav
   distractions.
2. **Problem/agitation** — name the pain precisely so the visitor feels seen.
3. **Solution** — how it works (3 steps max); product truth, not marketing fluff.
4. **Proof** — real results, real testimonials (with attribution), real logos.
5. **Objections** — pricing FAQ, security, onboarding time.
6. **CTA repeat** — with urgency that is honest ("limited launch pricing", not
   fake countdowns).

## Design rules
- One primary CTA style; secondary actions visually quieter.
- Above the fold fits 100vh on mobile; hero passes the 5-second scan test.
- Form fields minimized (email only unless more is proven).
- Performance: < 2s LCP; no heavy hero animation blocking the message.

## Rules
- No invented metrics/testimonials — ever.
- A/B test the headline and CTA copy after launch; record results.
